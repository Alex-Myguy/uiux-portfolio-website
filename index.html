UX Case Study • 2025 • Benin City Hub Focus

IKU — Localized Event Discovery & Instant Ticketing Platform

Bridging informal social media flyer discovery, street navigation ambiguity, and gate check-in bottlenecks across regional hubs through dynamic Digital Access Passes and custom invitation generation.

ROLE Lead Product & UI/UX Designer
TIMELINE 5 Weeks (Sprint & Prototyping)
TOOLS Figma
CORE IMPACT 3-Step Streamlined Flow
01 / Problem & Impact

Fragmented Discovery & Regional Friction

In high-growth regional hubs like Benin City, social events and nightlife heavily rely on informal WhatsApp broadcasts and Instagram flyers. This fragmented ecosystem leads to three core operational breakdowns:

🔍

Lost Event Info

People struggle to find ticket links or event details after seeing a flyer once.

📍

Venue Confusion

Venues often lack exact street addresses, making GPS navigation unreliable.

🎟️

Slow Door Check-Ins

Manual guest lists and paper tickets cause long queues and gate bottlenecks.

02 / DESIGN SYSTEM

Atomic Foundations & Nightlife Palette

Built from the ground up in Figma using an atomic structure, variable color tokens, and a clean sans-serif scale engineered specifically for high-contrast visibility in dark environments.

03 / CORE UX FLOWS

4-Step Frictionless Booking Loop

To prevent drop-offs, the core checkout interaction is constrained to a 4-screen loop supported by persistent sticky bottom action bars and Smart-Animate state changes.

01

Explore & Discover

Filter by location tags, categories (Nightlife, Concerts), and search terms.

02

Event Details

Preview landmark directions, lineup, and select ticket tiers (VIP / Regular).

03

Instant Checkout

1-tap payment integration with dynamic total price computation.

04

Digital Access Pass

Generate anti-fraud dynamic QR code for instant venue entry scanning.

04 / UX DIFFERENTIATORS

Key Product Innovation Pillars

01. Interactive Map Pins & Bottom Preview Cards

Users can toggle between list mode and an interactive Map View (`Map View`). Selecting map pins instantly triggers bottom preview cards displaying venue distance, pricing, and landmark references before committing to a route (`Route & Venue Directions`).

02. Custom Invitation Studio & Viral Pass Generator

Hosts and attendees can generate customized, stylized event invitation graphics directly inside the app (`Custom Invitation Generator`). This turns every attendee into an organic promoter, solving acquisition costs for local hosts.

03. Anti-Fraud Dynamic Check-In & Error States

Includes robust edge-case coverage:

  • "No Events Found" Empty State: Recommends trending categories instead of dead ends.
  • Instant QR Validation: Real-time success/failure feedback states (`Ticket Booked Successfully` vs `Error State: Invalid QR/Pass`) for rapid gate verification.
05 / IMPACT & TAKEAWAYS

Usability Validation & Strategic Learnings

3.2x
Faster Checkout Velocity

Reduction in average task completion time during unmoderated user testing vs. traditional web portals.

92%
Landmark Recognition Rate

Testers successfully identified event venues using local landmark cues rather than relying on exact street addresses.

0s

Instant offline QR generation enabled reliable access pass retrieval even under congested network conditions.

Key Insight: Localized Grounding Beats Generic Templates

Designing explicitly for regional infrastructure realities—such as prioritizing recognizable landmarks over standard street numbers and engineering offline dynamic QR passes—drove significantly higher user confidence and reduced checkout friction during concept testing.

Case Study

EduPulse — Institutional Analytics & Admin System

Architecting a unified atomic design system and tokenized interface architecture for enterprise academic management.

Role

Lead Product Designer & UI/UX Architect

Scope

Design System, Admin Portal, Data Visualization, Telemetry UI

Tools

Figma, Untitled UI, Variable Design Tokens, Tailwind CSS

Timeline

4 Weeks (Concept to Component Library)

01 / The Challenge: Taming Administrative Complexity

Modern enterprise academies and bootcamps manage thousands of active learners across scattered learning tracks, resulting in fragmented metrics. Academic directors and instructors wasted valuable hours cross-referencing CSV exports, manually tracking down overdue assignments, and monitoring student risk indicators across disjointed legacy software.

"How might we distill complex academic pipelines, multi-cohort attendance logs, and real-time student performance scores into a single glanceable interface without cognitive overload?"

02 / UX Strategy & High-Density Architecture

To solve the data-density challenge, EduPulse was architected using a modular grid layout prioritizing progressive disclosure and zero-friction navigation:

Split-Screen Telemetry Drawer

Selecting any student instantly opens an auxiliary slide-over panel displaying real-time assignment completion donuts, attendance rates, and direct intervention tools (messaging or remedial course assignment) without losing context of the parent list.

Variable Design Tokenization

Engineered using scalable Figma design tokens supporting seamless light/dark mode toggling, high-contrast accessibility compliance, and strict layout spacing rules for dense tabular data.

Smart Cohort Pipeline Filters

Advanced filtering matrices allowing academic directors to instantly filter 2,450+ student records by active status, risk level, or specific regional cohort branches.

03 / Component System & Data Architecture

The UI system was constructed from the ground up to ensure consistency across complex data tables, modal dialogs, and analytical trend charts:

  • Atomic Table Architecture: Compact table rows with custom status badges (`Graded`, `Under Review`, `Overdue`) that use clear visual color-coding for instant triage.
  • Real-time KPI Summary Cards: Top-tier overview metrics tracking course completion jumps, active user spikes, and engagement trends with micro-sparklines.
  • Contextual Action Triggers: Bulk export controls (`Export CSV`) and quick-action toolbars that reduce multi-step navigation clicks by over 40%.

04 / System Outcomes & Quantifiable Impact

Key Reflection & V2 Roadmap

Building EduPulse reinforced the core principle that density does not equal clutter. By carefully structuring visual hierarchy, whitespace, and contextual slide-over drawers, complex enterprise data becomes actionable rather than overwhelming. The upcoming V2 roadmap will integrate automated AI-driven predictive dropout alerts directly into the instructor telemetry view.
